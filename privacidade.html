Política de Privacidade - Zyon Bate-Ponto

Última atualização: 03/08/2026

Dados utilizados

O Zyon utiliza informações necessárias para funcionamento, como configurações do servidor, cargos, canais e registros do sistema.

Uso das informações

Os dados são usados somente para funcionamento e melhoria do bot.

Compartilhamento

O Zyon não vende ou compartilha dados dos usuários com terceiros.

Segurança

São aplicadas medidas para proteger as informações utilizadas pelo sistema.
